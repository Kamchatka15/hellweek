# Design pattern library

The durable knowledge base behind Phase R and Phase D. Each card is a retention or monetization pattern studied the same way: what it is → why it works (the psychology) → real games that prove it → when it has merit → how it fails → how we'd apply it. Claude reads this at design time and adds a card every time a new pattern earns study. This is how the studio gets faster and sharper per game instead of re-deriving the craft each time.

Rule: a system goes into a game only when it clears the "merit conditions" on its card. Reflexively bolting on a leaderboard or an event because "engagement" is how you build a game kids bounce off of.
