# Teardown — Grow a Garden (Splitting Point / Do Big Studios) — the offline + appointment archetype — 2026-09-12

> Public sources: PIPELINE §1 and doctrine (22.3M peak CCU, an industry record; built in 3 days by a 16-year-old; "offline growth that respects bedtime"), public gameplay, the game's wiki. Robux prices not asserted — *verify at G2*. Doctrine §3.1: copy the shape.

| Field | Value |
|---|---|
| Category | **collect / idle** — plant → wait (online or offline) → harvest → sell → better seeds |
| Numbers now | The largest game in Roblox history by peak concurrent (22.3M). Still enormous; exact CCU varies by hour |
| Wave stage | **Post-peak evergreen** — the rare wave that turned into a platform |
| **First 60 seconds** | Spawn on your plot → seed shop next to it → buy a cheap seed with starter money → plant → **it grows in real time while you watch the first one** → harvest → sell to the NPC → buy two seeds. First sell inside the first minute |
| **Core verb + reward cadence** | Plant / harvest. Crops grow on real-time timers; value scales with rarity and *mutations* (weather events change crops) |
| **Meta loop** | Rarer seeds, mutations, pets that boost growth, gear (sprinklers). The **seed shop restocks on a timer** (~5 min) with a random rare — an in-session appointment |
| **Social loop** | **Very strong:** visit friends' gardens, gift crops, trade, show off mutated crops, admin-abuse events everyone experiences together and clips |
| **Return hook** | **Offline growth** — your garden grows while you are away, *and it is never punished*: nothing rots for being late. The doctrine's "respects bedtime." Plus the shop restock timer, plus weather events |
| Event cadence | **Saturday updates as appointment viewing**; frequent live "admin abuse" giveaway events; weather events on a schedule |
| **Monetization catalog** | Seed packs, rare seeds, pet eggs, gear, cosmetics — every SKU **accelerates or displays** the garden you already love. First purchase is cheap and overdelivers |
| **Complaints = the wedge** | Scam-trading; server lag at peak; RNG on mutations (odds not always readable) |
| **Style spec** | Bright pastel low-poly; oversized cartoon crops; readable at 200px because every object is a single saturated colour; cozy, no threat; thumbnail = one giant mutated crop + a face |
| Creator Store equivalents | search: `low poly garden`, `cartoon plant`, `stylized farm props` |
| **Copy this** | 1 · **offline progress that is capped, not punished** — our offline design is already this; the *number* was wrong, not the idea. 2 · **a restock timer** = an in-session appointment (Fat Man: a timed "golden flood"?). 3 · **weekly update as an event** with a countdown in-game. 4 · **gift / show-off surfaces** — the social loop we lack. 5 · **mutations** = rare variants of the thing you already collect (rare coin types) |
| **Do not copy this** | Trading before scam-guards exist; undisclosed-odds randomness; any asset or name |

## Notes
Grow a Garden and Mine a Mountain bracket Fat Man Gets Rich: one proves the offline-and-events return hook at planet scale; the other proves bag-and-bank still pulls 131K in 2026 and then dies without a social loop. Fat Man is the bag-and-bank loop with Grow a Garden's return hook. What it has from neither, yet, is the social/clip surface — and that is the thing that separates the evergreen from the fading wave.
