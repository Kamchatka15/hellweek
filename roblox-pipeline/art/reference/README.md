# art/reference — the board to re-engineer from

> Justin's request 2026-09-12: a folder of the comps' graphics to work through and rework by hand. **What can go here:** public storefront art — icons, thumbnails, screenshots from the store page and public video — as *reference*, exactly as any artist keeps a mood board. **What cannot:** the games' meshes, textures, audio or scripts. Not a taste rule: Studio cannot open another creator's place, the tools that rip them are exploit tooling that gets the account banned, and a reworked rip is still their asset and gets flagged. Nothing in this folder ever ships. Ship the Creator Store shelf and originals made in this style (`research/2026-09-12-style-spec-fat-man.md`).

## How to use it
1. Open each store page; save the icon, thumbnail, and 2–3 screenshots into a subfolder named after the game (`01-mine-a-mountain/` …). Public images, reference only.
2. Circle what to *re-engineer*: a colour, a silhouette, a HUD layout, a thumbnail composition. Write it in one line in `NOTES.md` here.
3. Hand the note to the build: it becomes a Creator Store search, a Cube 3D / Ideogram prompt, or a `theme.luau` colour — an original in the style, not the image.

Reference images are never committed to the repo (`.gitignore`), so the folder stays yours and stays out of the game.

## Audio reference — same rule (added 2026-09-12)

You can keep a list here of *what the comps' audio feels like* (tempo, mood, instrument) to brief a generator or a Creator Store search. You cannot rework another game's actual audio file: Roblox fingerprints audio on upload and pulls re-uploads, and it is still their track after an edit. The fast legal fill is the Creator Store shelf in the style spec.

## Why this folder is for YOU, not for automated copying

Justin asked for the graphics/audio "that Claude won't work through" to be copied here to rework by hand. The folder is set up for that — **you** save public store images and audio references into it and rework them as you see fit; that is your call as the owner. What the build will not do is auto-download other creators' assets to produce minor-edit derivatives, because a reworked rip fingerprints as the original and gets the title pulled **after Gate B** — the exact moment the metrics you want finally exist. The whole point of the reference board is to feed *original* work (a Creator Store search, a generation prompt, a theme colour), not to launder a copy.
