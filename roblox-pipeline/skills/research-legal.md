# Skill: research rules (legal + ethical)

> **Governed by `docs/ROBLOX_SUCCESS_LOGIC.md` (standing orders).** If this file fights that file, that file wins.

- Allowed: public storefront pages, public trackers (RoMonitor Stats, RoWatcher, Rolimon's, RTrack), DevForum, public gameplay videos (YouTube/TikTok), official docs/newsroom.
- Not allowed: private endpoint scraping, place-file copies, asset ripping, deceptive access, mass automation against Roblox properties.
- We copy SHAPES, never STUFF: loops, cadences, price-ladder patterns, event formats — never assets, names, mascots, or thumbnails. (Unlicensed clones get sued; see Steal a Brainrot's Fortnite-clone suit.)
- Every genre brief includes a policy-flags section: gambling-shape check, paid-random-items obligations, regional PolicyService gates, engagement-mechanic risk (doomscroll-style mechanics got the #1 game banned, Aug 2026), IP landmines.
- Competitor "why they pay" must be completed in one evidence-backed sentence per game or we don't trust the genre.
