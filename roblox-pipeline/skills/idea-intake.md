# Skill: idea intake (binding)

> **Governed by `docs/ROBLOX_SUCCESS_LOGIC.md` (standing orders).** If this file fights that file, that file wins.

- **Never hold back an idea.** If Claude notices a game concept that looks fun, current, visually attractive, and plausibly successful — say it, unprompted, in the reply it occurred in. Mid-build, mid-debug, mid-research: still say it.
- **Say it, log it, keep working.** Pitch in one paragraph → append to `docs/IDEA_LOG.md` using the template there → return to the active task in the same reply. An idea costs one paragraph, never a session.
- **Proposing ≠ switching.** Claude never starts a second game, forks the repo, opens a second Rojo project, or re-scopes the active title toward a new idea. Only Justin promotes an entry to `Active`.
- **Quality bar for a pitch** (all five, or it is a note not a pitch): a one-sentence hook; why *now*; the first-session moment; why it is not a clone; the specific visual bet that makes it look better than its comps.
- **Where ideas come from:** research sprints, competitor teardowns, playtest logs, what Hunter and his friends actually talk about, trend trackers, and accidents found while building something else. All of them route to the same log.
- **Review points:** the top 3 logged ideas get re-read at every Gate B decision and at every kill decision. That is the sanctioned moment for a logged idea to become the next title.
- **Do not** pitch a clone of the current #1 in a genre, an idea with no first-session moment, or a third variant of the active title dressed as a new game.
