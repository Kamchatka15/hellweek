# Skill: live-ops conventions

> **Governed by `docs/ROBLOX_SUCCESS_LOGIC.md` (standing orders).** If this file fights that file, that file wins.

- Cadence: weekly micro-drop (1 theme, 1 SKU, 1 fix) same day/time weekly, announced in-game with countdown; monthly bigger theme; quarterly tentpole.
- Update-day-as-event: login gift, one new thing to want, one thing fixed, kid-readable changelog. Scheduled generosity events (giveaway hours) build appointment habits — give, don't take.
- Purchases get their "why" from events: SKUs launch attached to a moment, never as a bare catalog row.
- Tuning: Roblox native Experiments (ConfigService, ≤2 variants + control, 14–60 days, auto D1/D7/ARPU/significance). Conditional configs for no-restart changes. Change one variable per experiment.
- Weekly KPI review vs. the game's contract: D1, D7, session length, funnel join→first-reward, payer conversion, ARPDAU; real-time alerts + segmentation (tenure/spend/engagement) in Creator Hub.
- Kill/scale rules: D1 <15% after 3 hook iterations → farewell event, learnings doc, archive. Scaling → creator spend + second SKU lane + event depth.
