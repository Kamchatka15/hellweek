# Skill: art & audio pipeline

> **Governed by `docs/ROBLOX_SUCCESS_LOGIC.md` (standing orders).** If this file fights that file, that file wins.

- Order of preference: Studio Assistant/Cube 3D + Texture Generator (free, first-party) → Creator Store assets (free/licensed) → external gen (Meshy/Tripo/Hunyuan3D for 3D; Ideogram/Recraft for 2D) → human artist (Talent Hub) when a thumbnail carries a launch.
- Formats: icon 512×512; thumbnail 1920×1080, readable at 200px (one face, one verb, ≤3 words). Textures png/jpg/tga/bmp ≤4K, prefer 256–1024 for props.
- Audio: Creator Store licensed library first (music especially — licensing is Roblox's problem). Own uploads: private-by-default (fine for our experiences), 7 min / 20MB / ≤48kHz, 100 uploads/30d (2,000 ID-verified). SFX: ElevenLabs (paid tier for commercial) or code-generated chiptune.
- Prohibited: third-party IP (real meme/brand/coin logos, other games' mascots), confusingly-similar clones, photoreal minors. AI output is never exempt from moderation — pre-check before upload.
- Naming: art/<category>/<thing>_vN.png; wire-in specs (ImageLabel refs) accompany every approved asset.
