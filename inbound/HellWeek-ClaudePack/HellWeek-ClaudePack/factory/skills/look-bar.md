# Skill: look-bar

Trigger: dressing, art, style, thumbnail, "make it look like the top games."

MCP / Cube / Assistant generate props. They do not own the look.

Order:
1. Write five style lines (silhouette, ground+accent, light source, meter+destination, mood).
2. Store search by silhouette, insert by ID, recolor to the two-colour spec.
3. Lock lighting.md (Atmosphere, ColorCorrection, Bloom, destination PointLight). Apply before calling it dressed.
4. One hero collectable. Short Cube prompt or image-to-3D + remesh ≤15k tris. Third regenerate = primitives + paint.
5. Icon 512 and thumb 1920×1080 from an image tool. Formula: one face or silhouette, one giant collectable, ≤3 words. Not a Studio screenshot.
6. Run look-bar checks (200px, destination readable from spawn, one meter, two colours, no default lighting, no owned IP) before MCP four-beat.

Never: rip meshes; search Store by another game's name and paste the pack; ship the reference board; spend on Talent Hub before the 200px test has failed twice.
