## Paste into CLAUDE.md (do not replace the safety block)

SAME-DAY SLICE MODE (v1.3)

1. When Justin names a game and writes four paragraphs, do not ask him to fill a form. Draft brief.md. Query the ledger. Start the comp hunt.
2. Pull 3–10 live comps in the verb family by CCU. Fill TEMPLATE.md. Blend three. Never one-source clone.
3. Propose every applicable shape. Auto-cut to the budget. Draw the line. Park the rest. Wait two minutes. Then build.
4. Copy loops, cadence, HUD density, colour logic, appointment rhythm, thumbnail formula. Insert Store assets by ID. Generate the rest in the blended style. Never rip. Never ship owned names. Treat R6 as a Phase-1 block.
5. You are not done when code compiles. You are done when Studio MCP has a green four-beat run log and persistence survives restart.
6. Grey box is not a deliverable. Dress from the shelf before you call it Phase 1.
7. Silence proceeds on reversible work. Listing, paid products, ads, title-kills and rule-lowering wait for a human click.
8. Write session-close + STATE.md before you stop. File evidence with context. Hypotheses live in the brief.
9. Do not start a second title mid-build because a new idea looks fun. Log it in IDEA_LOG.md and keep building.
10. If this file fights ROBLOX_SUCCESS_LOGIC.md on safety, money, children, or publishing, the doctrine wins.

## MCP four-beat (definition of "built")

1. Join — no error spam, player can move, first action is obvious.
2. First earn — a number goes up within 60s.
3. First spend / bank — server-authoritative sink. Screenshot.
4. First upgrade + persist — kill-and-rejoin keeps the upgrade.

Write `docs/runs/YYYY-MM-DD-<slug>-mcp.md` every time.

## Copy matrix (short)

DO: verbs, cadence, first 60s, HUD density, colour logic, appointment timers, price-ladder *shape*, Store assets by ID, generated-in-style meshes/icons, tracker stats.

NEVER: ripped meshes/textures/audio/scripts, owned names/mascots/logos, private endpoints, fingerprinted "free" audio named after another game, single-source clones.

WORKAROUND: Creator Store search by silhouette → insert by ID. Rename every tier in-theme. Reference board is git-ignored and never ships.

## Silence policy

Proceed on silence: brief draft, G1 pitch pick, cut-line, Candidate economy, thumbnail pair, research, evidence, evidence-justified cap moves.

Never proceed on silence: listing, paid products, ads, killing a live title, lowering a safety rule, spending money.

## Honest metrics clock

- Same day: MCP four-beat, first-action time, loop completion, optional 3-kid comprehension, 200px thumb.
- Next morning after listing: impressions, join rate, first-session completion, organic spends, then D1.
- D1 is not a same-day number. Ads are not a night-zero action.
